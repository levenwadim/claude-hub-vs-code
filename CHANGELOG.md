# Changelog

## 0.1.0

First public preview.

- Sessions of Claude Code grouped by project (a repository and its worktrees form one project).
- Search by title and by session content.
- Unread status (blue dot) and **Mark as unread / read** in the session context menu.
- Read-only history viewer that loads older messages on scroll and follows new ones live.
- Open sessions in the Claude Code editor tab, the Claude Code sidebar (default), or a terminal (`claude --resume`).
